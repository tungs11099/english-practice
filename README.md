# 英文星球｜國小三年級英文練習

純前端、免安裝的英文練習小系統，使用 HTML、CSS、JavaScript 和瀏覽器的 `localStorage`／`SpeechSynthesis`。沒有後端、帳號或外部付費 API。初始內建 55 個入門單字，包含動物、水果、顏色、數字、家庭、學校用品與日常生活。

## 專案檔案

- `index.html`：頁面結構與導覽
- `style.css`：色彩、元件、動畫及手機版版面
- `js/words.js`：單字、例句、翻譯、分類及圖示資料
- `js/quiz.js`：洗牌與選擇題題目產生
- `js/storage.js`：學習紀錄、錯題的瀏覽器儲存
- `js/app.js`：畫面切換、答題互動、發音與統計

## 開啟方式

在檔案總管中直接開啟 `index.html`，或在 Chrome 將該檔案拖入瀏覽器。也可以在專案資料夾啟動簡單的本機伺服器，例如 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。無須安裝依賴或編譯。

## 功能檢查方式

1. 點首頁每個功能卡片，確認會進入單字、選擇題模式、看圖猜字、錯題或紀錄頁。
2. 單字頁切換分類、前後翻卡，再按「聽發音」。Chrome 首次發音通常需要使用者點擊。
3. 分別進行三種選擇題：每回合 10 題、每題 4 個選項；答對 10 分，答錯會顯示正確答案和中文解釋。
4. 刻意答錯，從首頁進入錯題複習；再次答對後，該字會從待複習清單移除，但答題統計仍保留。
5. 查看學習紀錄並重新整理頁面，確認統計仍存在。紀錄儲存在目前瀏覽器的本機網站資料中。
6. 將 Chrome 視窗縮窄或使用手機，檢視按鈕、選項與卡片是否適合觸控操作。

## 新增單字

編輯 `js/words.js` 的 `WORDS` 陣列，複製一筆並修改 `en` 英文、`zh` 繁體中文、`emoji` 圖示、`category` 分類、`sentence` 例句與 `translation` 翻譯。分類名稱會自動出現在單字頁。圖示使用 emoji，不需要下載圖片。

## 已知限制

- 語音由瀏覽器和作業系統提供；可用聲音、口音及發音品質依裝置而異，瀏覽器或裝置不支援時會顯示提示。
- 學習紀錄只存在目前瀏覽器的本機儲存空間；清除網站資料、換瀏覽器或裝置後不會同步。
- 圖片題使用 emoji 圖示，沒有外部圖片檔；字型使用裝置上的系統字型，無需連線載入外部資源。
- 「已學習單字」代表在測驗中遇過的不同英文單字，不是單字卡瀏覽次數。
- 本機 `file://` 模式在不同瀏覽器對 `localStorage` 的處理可能略有差異；如遇到儲存問題，可使用上方的本機伺服器方式開啟。
